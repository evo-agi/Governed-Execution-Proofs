# Governed Lifecycle Filming Script

## Status

Canonical filming and public-demo recording-package material now lives in
`Governed Execution MVP Filming Preparation/.docs/`.

This proof-repo file is retained as a pointer only. Use the filming-prep
package for:

- filming/demo scripts, narration packets, screen plans, and recording
  checklists;
- safe-field lists, hide/redaction lists, and screen-safety rules;
- public-facing demo wording and claim guardrails for recording use.

The Governed Execution Proofs repo remains source authority for proof packages,
proof ledgers, evidence maps, validation plans, proof policies, run identifiers,
claim/non-claim discipline, and recorded proof status. Proof evidence and proof
ledgers remain here; they are not moved into the filming-prep repo.

## Authority Boundaries

- CP, ES, and IM source authority remains in the owning repos.
- Proof evidence and proof ledgers remain in Governed Execution Proofs.
- Generated artifacts are never copied between repos for recording purposes.
- Reports, traces, logs, retained bundles, support bundles, prompts, model
  outputs, workspaces, databases, credentials, endpoint values, and local
  process records remain excluded from this authored pointer.
- Recording readiness and public readiness are not claimed by this pointer
  cleanup.
